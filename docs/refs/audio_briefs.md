# RideRash soundtrack — briefs

Original instrumental music and SFX generated with Atlas for this game
(project "RideRash Audio"). The register is the 90s bike-combat racer —
researched, not copied:

- 16-bit era: heavy-metal / bluesy hard rock with a synth lead line
- 1994 CD era: grunge, alt-metal and space-rock — detuned fuzz riffs, big
  live drums, dirty and rebellious

Rules the prompts followed: instrumental only, no vocals; no artist, band,
song or game named or imitated; loop-friendly (steady tempo, no fade-out).

| file | brief |
|---|---|
| title | early-90s alt-metal / grunge anthem: a lone detuned riff, then drums and fuzz bass crash in; 120 bpm, drop-D |
| race1 | relentless hard rock / space rock, 150 bpm, fuzz wall, galloping bass, wah lead with feedback swells |

| race3 | 16-bit-inspired metal played by a band, 145 bpm, palm-muted chugs, double kick, bright FM-synth lead |
| win / bust | 6-8 s triumphant / ominous rock stingers |
| rev, select, move | V-twin rev-away; guitar pick-scrape + kick confirm; metallic tick |
